# Projeto Completo de Cardápio Digital

Este repositório contém um projeto de **Cardápio Digital** desenvolvido do zero utilizando **HTML**, **CSS**, **TailwindCSS** e **JavaScript**. O objetivo é criar um cardápio interativo, responsivo e dinâmico, ideal para restaurantes, lanchonetes e outros estabelecimentos.

O projeto foi inspirado pelo vídeo tutorial **"Criando projeto profissional do zero - HTML, CSS, TailwindCSS, JavaScript"**.

## Funcionalidades

- **Interface Responsiva**: O cardápio se adapta a diferentes tamanhos de tela, oferecendo uma excelente experiência de usuário em dispositivos móveis e desktop.
- **Exibição de Itens do Cardápio**: Apresentação de itens com nome, descrição e preços de maneira organizada.
- **Filtros e Categorias**: Filtros interativos para visualizar categorias de alimentos ou bebidas de forma simples.
- **Design Moderno e Personalizado**: Estilo moderno e customizável com **TailwindCSS**.

## Tecnologias Utilizadas

- **HTML5**: Estrutura básica do cardápio e layout.
- **CSS**: Personalização de estilos.
- **TailwindCSS**: Framework CSS para criar um design responsivo e moderno.
- **JavaScript**: Para adicionar interatividade no cardápio, como filtros e animações.
